# Android implementation area

This directory reserves the canonical location for future Android work. It
contains no app, runtime, VM engine, SDK configuration, Gradle project, wrapper,
native library, image, or dependency declaration.

The [roadmap](../docs/roadmap.md) authorizes only Gate 0 research next. A later,
separately reviewed minimal authority experiment must be scoped to a credible
candidate; complete-guest implementation requires Gate 0 to pass. The initial
guest target is Android 17 / API 37; this does not set the host minimum SDK.

Historical Android scaffolding and probes require architectural and provenance
review before any reuse. See [reuse classification](../docs/reference/privacy-decoy-history/reuse-classification.md).
